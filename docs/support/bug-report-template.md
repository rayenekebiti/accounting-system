# Bug Report Template

Copy this into a new issue. The support bundle answers most of the environment questions
automatically — attach it.

```
## Summary
<One sentence: what's wrong.>

## Severity (your best guess)
SEV-1 (data at risk) / SEV-2 (blocked) / SEV-3 (bug, workaround exists) / SEV-4 (minor)

## Steps to reproduce
1.
2.
3.

## Expected result
<What should have happened.>

## Actual result
<What actually happened. Exact error wording if any.>

## Frequency
Every time / Sometimes / Once

## Environment (from the support bundle buildinfo.json)
- Occountant version:
- Build / channel:
- Git commit:
- Windows version:

## Support bundle
Attached: yes / no
(Settings → Diagnostics → create support bundle. It contains NO accounting data.)

## Workaround
<Any way to avoid it in the meantime.>

## Notes
<Anything else — recent updates, unusual setup, portable mode, etc.>
```

**Reminder:** never paste a customer's customers, invoices, payments, or amounts into an issue. The
support bundle is designed so you don't have to.
