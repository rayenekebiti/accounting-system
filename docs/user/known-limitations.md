# Known Limitations (Version 1.0)

We believe in being straight with you about what Occountant 1.0 does and doesn't do. None of the
items below affect the correctness or safety of your books — they're features that aren't in this
first release. Many are on the roadmap.

## Platform

- **Windows only.** Occountant 1.0 runs on Windows 10 and 11 (64-bit). A macOS version is planned.

## Working style

- **Single computer, single user.** Your books live on one computer and are used by one person at a
  time. There is no simultaneous multi-user access and no networked/shared database. To use another
  computer, move a backup (see the Migration Guide).
- **No cloud or sync.** This is deliberate — your data stays private and offline. Cloud backup/sync
  is being considered for a future version, but 1.0 is offline-first by design.

## Importing and exporting

- **No import from other tools.** Occountant 1.0 doesn't import from spreadsheets or other
  accounting software. You start by entering opening balances and going forward. Import is on the
  roadmap; contact support if you have a large existing dataset.
- **No built-in invoice PDF / email delivery.** Occountant 1.0 records and tracks invoices but does
  not yet generate a printable/emailable invoice document to send to your customer. This is a
  priority roadmap item.
- **Statement export is limited.** You can view the Trial Balance, Ledger/Journal, and VAT summary
  on screen. Formatted, exportable financial statements (printable P&L / balance sheet) are planned.

## Convenience

- **No application-wide keyboard shortcuts yet.** Full keyboard *operation* works today (Tab,
  Enter, Space, Esc, arrows); dedicated accelerators like Ctrl+N for a new invoice are planned.

## Accessibility

- The interface exposes proper names to screen readers and mirrors correctly for right-to-left
  Arabic. The **spoken screen-reader experience** and **very large system-font / high-contrast OS
  themes** are verified manually and polished per release; if you rely on these and hit a rough
  edge, please tell us with a support bundle.
