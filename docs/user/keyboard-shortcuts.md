# Keyboard Shortcuts & Keyboard Operation

Occountant can be operated entirely from the keyboard — useful for fast data entry and required for
some accessibility tools.

## Moving around

| Key | Action |
|---|---|
| **Tab** | Move to the next control |
| **Shift + Tab** | Move to the previous control |
| **Enter** / **Space** | Activate the focused button or item |
| **Esc** | Close the open dialog (same as Cancel) |
| **Arrow keys** | Move within lists and menus |

The control that currently has focus is shown with a highlighted ring, so you always know where you
are.

## Dialogs (editors)

- When you open an editor (New Invoice, New Customer, etc.), focus lands in the first field so you
  can start typing immediately.
- **Tab** moves field to field. The dialog keeps focus inside it until you close it.
- **Esc** cancels; the primary button (e.g. **Save**) confirms.
- When you close a dialog, focus returns to the button you opened it from.

## Navigation rail

- Tab to the sidebar and use **Enter/Space** to switch screens. The current screen is announced to
  screen readers.

## Right-to-left (Arabic)

In Arabic, the whole interface mirrors right-to-left, and Tab order follows the visual reading
order. Everything that works in English works identically in Arabic and French.

## Screen readers

Every button and field exposes a spoken name to Windows screen readers (Narrator, NVDA). Hidden
controls are not announced. If you use a screen reader and find a control that isn't announced
clearly, please report it with a support bundle.

> Note: Occountant focuses on complete, reliable keyboard operation. Application-wide accelerator
> shortcuts (e.g. Ctrl-key combos for New Invoice) are planned for a future release; see Known
> Limitations.
